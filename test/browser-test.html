🎤 Tekthib WebRTC Voice Chat Tester

📋 How to Use This Test Page

Purpose: This page allows you to test WebRTC voice chat from a single computer by opening multiple tabs/windows.

  • Step 1: Configure the server URL and number of peers below
  • Step 2: Click "Start Test" to automatically open multiple tabs
  • Step 3: Each tab represents a peer and will connect to voice chat
  • Step 4: Monitor the connection status and logs below
  • Step 5: Click "Stop Test" when done to close all tabs
⚠️ Important: Your browser may block popup windows. Please allow popups for this page to open multiple test tabs. You can also manually open this page in multiple tabs and connect them to the same room.
